# Examen Práctico - Sitio Web "Explora Tulcán"

## Datos del Estudiante
* **Nombre:** Marieta del Rocío Guzmán Cabrera
* **Materia:** Diseño de Sitio Web
* **Destino Asignado:** Tulcán - Provincia del Carchi, Ecuador

## Descripción del Proyecto
Sitio web completo para la agencia de turismo ficticia **Explora Tulcán**, creada con el objetivo de promocionar el patrimonio natural, cultural, histórico y gastronómico del cantón Tulcán. El sitio incluye 5 páginas estáticas semánticas, adaptables a móviles, tablets y computadoras de escritorio.

## Tecnologías Utilizadas
* HTML5 (Estructuración semántica y formularios interactivos)
* CSS3 (Diseño responsive con Flexbox, CSS Grid y Media Queries)
* Git (Control de versiones)
* GitHub & GitHub Pages (Alojamiento y despliegue del sitio)
